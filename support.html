Common questions

Apps didn't pause when a focus block started. Check that Screen Time access is still on (Settings → Screen Time → Apps with Screen Time Access → Focus Coach), and that you picked apps or categories to pause in the Focus tab. Focus blocks run by themselves, so the app doesn't need to be open.

A block landed on a meeting. Focus Coach adjusts a plan when a meeting lands on a block that hasn't started yet: it shortens or moves the block and tells you. A block already in progress is left alone — tap Skip if you need your apps back.

I need an app during a block. On the shield, tap "I need it" twice for a 5-minute break. You get two per block, and the shield comes back on its own.

"Plan every weekday" didn't set today's plan. iOS decides when background refresh runs. Opening Focus Coach always sets the day's plan if it hasn't been set yet.

Remove the "Focus time" events from my calendar. Cancel the plan in the Focus tab and Focus Coach removes the events it added. Turn off "Block this time on my calendar" to stop adding them.

Subscription

Focus Coach Pro is billed by Apple. To cancel or change plans: Settings → your name → Subscriptions → Focus Coach. For refunds, use reportaproblem.apple.com.

Privacy
